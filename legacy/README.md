# Legacy implementation

This directory preserves files from the original script-based recommender experiment.

## Contents

- `scripts/` contains the original training, preprocessing, evaluation, model, and recommendation scripts.
- `artifacts/` contains the historical serialized user and movie encoders generated by the earlier workflow.
- Historical evaluation plots produced by that implementation are stored separately in `../results/legacy/`.

These files are retained for reference and reproducibility of the earlier experiment. They are not part of the maintained lint/test path and may depend on the original experiment environment. The maintained implementation is the installable package under `../src/recommender/`, with tests under `../tests/` and CI defined in `../.github/workflows/ci.yml`.
