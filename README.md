# Neural Movie Recommender with PyTorch

A reproducible neural collaborative-filtering project built on the MovieLens 1M dataset. It trains an embedding-based multilayer perceptron (MLP) for explicit-rating prediction and evaluates recommendations with **user-level** ranking metrics.

## Highlights

- PyTorch embeddings + multilayer perceptron
- Reproducible MovieLens 1M preprocessing
- Per-user train/test holdout
- RMSE and MAE for rating prediction
- Precision@K, Recall@K, and NDCG@K for personalized ranking
- Top-N recommendations that exclude items already seen during training
- CLI-based training and inference
- Unit tests, Ruff linting, and GitHub Actions CI

## Architecture

```text
MovieLens 1M
    │
    ▼
Load + encode user/movie IDs
    │
    ▼
Per-user train/test holdout
    │
    ├───────────────┐
    ▼               ▼
User embedding   Movie embedding
    └───────┬───────┘
            ▼
           MLP
            │
            ├── Rating prediction → RMSE / MAE
            │
            └── Unseen-item ranking → Precision@K / Recall@K / NDCG@K
```

## Evaluation methodology

The original experiment calculated Precision@K and Recall@K by selecting the highest-scoring predictions inside DataLoader batches. Because a batch can contain interactions from several users, that is not a conventional personalized Top-K ranking task.

The maintained implementation evaluates users independently. For each user, candidate items are movies not present in that user's training history. The model scores those candidates, selects Top-K, compares the ranking with relevant held-out items, and macro-averages the results across eligible users.

Historical plots from the original experiment are preserved under [`results/legacy/`](results/legacy/) for reference. They are not presented as results from the revised ranking pipeline.

## Setup

Python 3.10+ is required.

```bash
git clone https://github.com/BrianVisas/Recommender_System_With_Pytorch.git
cd Recommender_System_With_Pytorch
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"
```

Download **MovieLens 1M** from GroupLens and place `ratings.dat` and `movies.dat` in a local directory such as `data/ml-1m/`. Dataset files are deliberately excluded from version control.

## Train

```bash
movie-recommender train \
  --ratings data/ml-1m/ratings.dat \
  --movies data/ml-1m/movies.dat \
  --epochs 20 \
  --output artifacts
```

Device selection defaults to `auto`, choosing CUDA, Apple MPS, or CPU depending on availability. Training stores only `best_model.pt` and `last_model.pt` rather than generating a checkpoint for every epoch.

`artifacts/metrics.json` records training history, best RMSE, and revised ranking metrics.

## Generate recommendations

```bash
movie-recommender recommend \
  --ratings data/ml-1m/ratings.dat \
  --movies data/ml-1m/movies.dat \
  --model artifacts/best_model.pt \
  --user-id 5 \
  --top-n 10
```

Movies already present in the selected user's training history are excluded from recommendation candidates.
